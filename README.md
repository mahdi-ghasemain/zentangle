# هنر زندگی — Zentangle

اپلیکیشن فارسی هنردرمانی زنتنگل با رابط راست‌به‌چپ مناسب سالمندان، بر پایهٔ تصویر مرجع. یک کد مشترک برای Android، iOS و وب؛ Expo SDK 57، React 19، React Native 0.86 و TypeScript 6. نسخه‌های دقیق و سازگار در package-lock.json ثبت شده‌اند.

## اجرای سریع

نیازمندی: Node.js 22.13 یا جدیدتر.

```powershell
cd D:\zentangle
npm ci
npm run web
```

برای توسعهٔ موبایل `npm start` اجرا کنید. سازگاری Expo Go باید با SDK 57 تطبیق داشته باشد؛ برای امکانات بومی از development build استفاده کنید. `npm run android` نیازمند محیط اندروید است. ساخت iOS از طریق EAS یا macOS انجام می‌شود.

```powershell
npx eas-cli@latest build --platform android --profile preview
```

این دستور نیازمند حساب Expo و پیکربندی شناسهٔ پروژه است. APK امضاشده در این تحویل ساخته نشده است.

## امکانات

- معرفی سه‌مرحله‌ای با عکس اختصاصی، ورود/ثبت‌نام ایمیلی و حالت آزمایشی مشخص.
- خانه، پیشرفت و ۱۲ جلسه با باز شدن ترتیبی؛ جلسهٔ گروهی پس از هر دو جلسه.
- اهداف و راهنمای پنج‌مرحله‌ای هر جلسه؛ تصویر برداری مرحله‌ای برگ؛ تمرین و نمونه‌ها.
- انتخاب عکس یا دوربین، نام و روایت اثر، ضبط و پخش صدا، تأیید اشتراک در گروه.
- گالری آثار، آثار من، علاقه‌مندی محلی، نمایش اثر و ثبت نظر.
- تقویم فارسی، خروجی ICS، ورود به سرویس جلسه با پیوند درمانگر.
- پروفایل، اعلان‌های داخل برنامه، فونت در سه اندازه، حالت تاریک، منابع و برگهٔ تمرین قابل چاپ، راهنما.
- پنل درمانگر برای مشاهدهٔ مشارکت، بررسی آثار/بازخورد، ویدیو و زمان‌بندی جلسه.

در حالت آزمایشی داده‌های نمونه با برچسب نمایش داده می‌شوند. پسندیدن آثار و تنظیمات روی دستگاه هستند. در وب عکس و صدا در حافظهٔ مرورگر ذخیره می‌شوند و محدودیت فضای مرورگر دارند؛ در موبایل فایل‌ها به مسیر پایدار برنامه منتقل می‌شوند. برای دادهٔ واقعی از اتصال سرور استفاده شود.

## اتصال واقعی

۱. در یک پروژهٔ تازهٔ Supabase، فایل `supabase/migrations/001_initial.sql` را اجرا کنید.
۲. `.env.example` را به `.env` کپی و URL و **کلید عمومی anon/publishable** را وارد کنید. هرگز service_role را در اپ قرار ندهید.
۳. Email Auth، تأیید ایمیل و تنظیمات ارسال ایمیل را در Supabase تنظیم کنید.
۴. کاربر با ثبت‌نام یک پروفایل participant دریافت می‌کند. مدیر مورد اعتماد از SQL Console گروه می‌سازد و group_id کاربران را تعیین می‌کند. نقش therapist فقط از محیط مدیریتی مورد اعتماد اعطا می‌شود؛ رابط برنامه اجازهٔ ارتقای نقش ندارد.

```sql
insert into public.groups(name) values ('گروه اول') returning id;
-- UUIDها را با مقادیر واقعی جایگزین کنید:
update public.profiles set group_id = 'GROUP_UUID' where id = 'USER_UUID';
update public.profiles set role = 'therapist', group_id = 'GROUP_UUID' where id = 'THERAPIST_UUID';
```

۵. با حساب درمانگر ویدیوهای تأییدشده و پیوند HTTPS سرویس تماس را ثبت کنید. ویدیو باید فایل قابل پخش مستقیم با CORS مناسب باشد. این تحویل سرویس کنفرانس مستقلی ندارد؛ ورود به سرویس انتخابی انجام می‌شود.
۶. برای بازیابی رمز، `EXPO_PUBLIC_AUTH_REDIRECT_URL` را به صفحهٔ بازیابی HTTPS خودتان تنظیم و در allowlist سرویس قرار دهید. تا تنظیم این جریان، دکمهٔ بازیابی پیام راهنما نشان می‌دهد. ورود Google و پیامکی پیاده‌سازی نشده؛ ورود ایمیلی واقعی آمادهٔ اتصال است.
۷. `EXPO_PUBLIC_SUPPORT_EMAIL` نشانی پشتیبانی را تعیین می‌کند.

## حریم خصوصی و محدودهٔ تحویل

دسترسی سرور با RLS محدود به گروه است؛ فایل‌ها خصوصی و دارای پیوند موقت‌اند. SQL و اتصال شبکه بدون حساب واقعی Supabase قابل آزمون انتهابه‌انتها نبوده‌اند. پیش از استفادهٔ پژوهشی، موارد `supabase/security-tests.sql` را در پروژهٔ آزمایشی بررسی کنید؛ رضایت‌نامه، مدت نگهداری، حذف/خروجی داده و محتوای آموزشی باید توسط تیم پژوهش تعیین و تأیید شوند. دادهٔ بالینی یا ادعای سنجش اثربخشی در این نسخه وجود ندارد.

ویدیوهای آموزشی نهایی، سرویس تماس، اعلان Push، ورود اجتماعی و اجرای مطالعه نیازمند خدمات/محتوای بیرونی هستند. اعلان فعلی صرفاً داخل برنامه است. نمودار برگ برای موضوع‌های مختلف یک نمونهٔ بصری مشترک است و برای هر ۱۲ جلسه دستورهای متنی اختصاصی وجود دارد.

## ساختار و بررسی

`src/app` مسیرها و محافظ دسترسی؛ `src/screens` صفحات؛ `src/components` اجزای بصری و نقوش برداری؛ `src/lib` داده و سرور؛ `src/data/program.ts` برنامهٔ جلسات؛ `supabase` ساختار و سیاست‌ها.

```powershell
npm run typecheck
npm run lint
npm run build:web
npm test
```

تست مرورگر علاوه بر این دستورات مسیر معرفی، آزمایش، قفل جلسات، ارسال اثر، نظر، ذخیره‌سازی و تنظیمات را بررسی می‌کند. گزارش دقیق در `VERIFICATION.md` ثبت می‌شود.

## تصویر اختصاصی
