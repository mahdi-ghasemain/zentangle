# فعال‌سازی کم‌هزینهٔ هنر زندگی
آخرین بررسی تعرفه‌های عمومی: ۸ اکتبر ۲۰۲۶. این فایل کلید یا رمز واقعی ندارد.

## آماده در کد
- ورود/ثبت‌نام دو مرحله‌ای با شماره و کد شش‌رقمی؛ فرستادن کد توسط LimoSMS.
- عکس پروفایل خصوصی: تبدیل به JPEG مربع ۵۱۲ پیکسل، فقط یک فایل برای هر کاربر، سقف ۲ مگابایت در سرور، ویرایش/حذف فقط توسط صاحب عکس و خواندن توسط اعضای گروه.
- تماس گروهی صوتی/تصویری LiveKit در نسخهٔ وب و نسخهٔ وب نصب‌شده روی موبایل. کلید مخفی در سرور، احراز هویت واقعی، کنترل عضویت گروه و زمان جلسه، توکن ورود ۵ دقیقه‌ای و حداکثر ۱۲ نفر در اتاق. دوربین و میکروفن از داخل تماس قابل تغییرند.
- صفحهٔ /install و آیکون‌های اندروید/آیفون. این خروجی PWA است؛ فایل APK یا انتشار App Store نیست. تماس بومی React Native در این مرحله پیاده نشده و از مرورگر باز می‌شود.
- صفحات آموزش ۱۲ جلسه، آثار، بازخورد، تقویم و پنل درمانگر موجودند. ویدیوها، زمان جلسات، عضویت گروه و نشانی پشتیبانی باید توسط مدیر واقعی وارد شوند.

## هزینه
- [LiveKit Build](https://livekit.com/pricing): فعلاً ۵۰۰۰ دقیقهٔ حضور افراد در ماه، ۵۰ گیگابایت ترافیک خروجی، ۱۰۰ اتصال هم‌زمان. جلسهٔ ۱۰ نفرهٔ یک‌ساعته ۶۰۰ دقیقه مصرف می‌کند؛ حدود ۸ چنین جلسه‌ای از نظر دقیقه، اما ممکن است سهمیهٔ ترافیک زودتر تمام شود. ضبط خودکار نداریم. [سهمیهٔ رایگان سقف سخت دارد](https://docs.livekit.io/deploy/admin/quotas-and-limits/) و بعد از اتمام، درخواست‌های جدید متوقف می‌شوند. برای این پروژه پلن پولی/ارتقای خودکار فعال نکنید.
- [Supabase Free](https://supabase.com/pricing): فعلاً ۵۰هزار کاربر فعال ماهانه، ۵۰۰ مگابایت دیتابیس، ۱ گیگابایت فایل و ۵ گیگابایت خروجی معمولی. این اعداد به معنی تحمل همهٔ این کاربران در تماس یا فضای نامحدود عکس نیست. توقف پس از یک هفته بی‌فعالیتی و نبود پشتیبان خودکار را در نظر بگیرید.
- [لیمو](https://limosms.com/): پنل رایگان است، ارسال از شارژ کم می‌شود. تعرفهٔ واقعی پترن و مالیات را از پنل بگیرید. هزینه = تعداد بخش‌های پیامک ارسال‌شده × تعرفه. ثبت‌نام، ورود مجدد و ارسال دوباره همه مصرف دارند؛ بازکردن مجدد برنامه با نشست معتبر پیامک تازه نمی‌خواهد.
- پیش‌فرض کد: ۱۰۰ تلاش ارسال در روز UTC برای کل سایت، ۵ تلاش برای هر شماره در روز و ۶۰ ثانیه فاصله. تلاش ناموفق هم سهمیه رزرو می‌کند تا خطاهای سرویس باعث مصرف بی‌حد نشوند. برای کاهش سقف، SMS_DAILY_LIMIT را مثلاً ۲۰ بگذارید. کد مجوز ارتقای اشتراک هیچ سرویسی را نمی‌دهد.

## مراحل حساب‌ها
1. در همان پروژهٔ Supabase، ابتدا مطمئن شوید مهاجرت 001_initial.sql قبلاً اجرا شده؛ آن را روی پایگاه موجود دوباره اجرا نکنید. سپس 002_profiles_calls_limits.sql را در SQL Editor اجرا کنید. نسخهٔ جدید send-sms بدون این مهاجرت عمداً پیامک نمی‌فرستد.
2. در [LiveKit Cloud](https://cloud.livekit.io/) حساب و پروژهٔ رایگان Build بسازید. URL پروژه، API key و API secret را فقط در Secrets بخش Edge Functions در Supabase قرار دهید: LIVEKIT_URL با wss://، LIVEKIT_API_KEY و LIVEKIT_API_SECRET. آن‌ها را در پیام چت، GitHub یا EXPO_PUBLIC قرار ندهید.
3. در همان Secrets، ALLOWED_ORIGINS را برابر آدرس HTTPS واقعی سایت، بدون مسیر و اسلش پایانی، قرار دهید. چند آدرس با کاما جدا شوند. فقط هنگام توسعه آدرس localhost لازم را اضافه کنید.
4. تابع livekit-token را deploy کنید؛ پیکربندی verify_jwt=false به این دلیل است که تابع خودش با Auth.getUser توکن را اعتبارسنجی می‌کند و مجوز گروه را جداگانه بررسی می‌کند.
5. مطابق SMS_SETUP.md، کلید لیمو، شناسهٔ پترن و امضای Send SMS Hook را تنظیم کنید، سپس send-sms را دوباره deploy و Hook و Phone provider را فعال کنید. SMS_DAILY_LIMIT=100 یا سقف کمتر دلخواه.
6. برای اجرای CLI از پوشهٔ پروژه:
   `npx supabase functions deploy livekit-token --project-ref PROJECT_REF`
   `npx supabase functions deploy send-sms --project-ref PROJECT_REF`
   قبل از deploy وارد Supabase CLI شوید. مقادیر محرمانه را از فایل محلی نادیده‌گرفته‌شده یا Dashboard تنظیم کنید.
7. در تنظیمات محیط میزبان، EXPO_PUBLIC_SUPABASE_URL و EXPO_PUBLIC_SUPABASE_ANON_KEY را قرار دهید. EXPO_PUBLIC_SUPPORT_EMAIL را نشانی پشتیبانی واقعی و EXPO_PUBLIC_WEB_URL را آدرس سایت HTTPS بگذارید. فایل ریشهٔ .env و فایل supabase/functions/.env وارد Git نمی‌شوند.
8. فقط از محیط مدیریتی مطمئن برای تعیین گروه و نقش درمانگر استفاده کنید. کاربر معمولی نمی‌تواند به خودش نقش درمانگر بدهد. در پنل درمانگر «تماس داخل برنامه» را انتخاب و تاریخ جلسه را ثبت کنید.
9. خروجی `npm run build:web` در dist ساخته می‌شود. صفحهٔ /install راهنمای نصب دارد. روی آیفون Safari → Share → Add to Home Screen و روی اندروید Chrome → Install app. تماس به HTTPS و اجازهٔ دوربین/میکروفن نیاز دارد؛ کیفیت در شبکهٔ واقعی کاربران داخل ایران باید بررسی شود.

## کنترل قبل از تحویل
- ارسال واقعی کد و تأیید آن با شمارهٔ متعلق به خودتان؛ آزمون با کد غلط و منقضی.
- دو حساب جدا: دسترسی نداشتن به عکس یا جلسهٔ گروه دیگر و امکان تعویض/حذف عکس خود.
- یک تماس واقعی با دو گوشی و آزمون صدا، تصویر، قطع اتصال و ورود دوباره.
- نصب روی یک اندروید و یک آیفون واقعی؛ هیچ نتیجهٔ آزمون مرورگر جای آزمون دستگاه را نمی‌گیرد.
- بعد از ساخت حساب، مقدار تعرفهٔ لیمو و سهمیه‌های داشبورد را ثبت کنید.
- محدودیت توکن ۵ دقیقه، زمان مجاز ورود است؛ کاربری که وارد شده با انقضای توکن قطع نمی‌شود. سقف مصرف ماهانهٔ LiveKit باید در خود پلن رایگان باقی بماند. این کد ادعای رمزگذاری سرتاسری رسانه ندارد.
- سقف کلی پیامک جلوی هزینهٔ بی‌حد را می‌گیرد، ولی مهاجم همچنان می‌تواند سهمیهٔ روز را تمام کند؛ فعال‌سازی CAPTCHA در آینده نیازمند افزودن رابط CAPTCHA به فرم و سپس تنظیم Supabase است.

## وضعیت تحویل
کد محلی و راهنمای استقرار آماده می‌شوند؛ فعال بودن سرویس‌های واقعی یا انتشار عمومی فقط بعد از تنظیم حساب‌ها و آزمون واقعی قابل تأیید است. کلید خصوصی در کد قرار ندارد.
